# client-patcher
Simple binary patcher that includes various bug and security fixes for the 3.3.5a client

## Patches:
 - Large Address Aware
 - stoneharry's Remote Code Exploit (RCE) fix
 - robinsch's WoWFix335 fixes
 - Recalculated PE checksum

## Usage
```
$ client-patcher <file_path>
```
